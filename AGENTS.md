# AGENTS.md · org proPosing

Se você é uma IA lendo esta org, comece aqui.

**O que é:** o proPosing transforma o computador num coach de pose de fisiculturismo. A câmera filma o atleta, a visão computacional compara com a pose de referência e mostra na hora o que ajustar, com nota em %. É um produto da [SABINVS PRODUCTIONS](https://github.com/sabinvs), de Goiânia.

**Este repo** é público e só guarda os templates de issue e PR da org e o perfil em `profile/`. Não entra aqui código, configuração nem informação interna. Os outros repos da org são privados.

**Trabalha para alguém do time?** O contexto completo (regras, papéis, fluxos, skills e IDs do quadro) está no kit de agentes, em `proposingapp/agentes`. Ele é privado, então o `gh` precisa estar logado na conta de um membro:

```bash
gh repo clone proposingapp/agentes
```

**Para quem é de fora:** o código é privado, e o projeto ainda não aceita contribuição externa.
