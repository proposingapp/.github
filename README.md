# .github · templates padrão da org

Este repositório guarda os templates de issue e de pull request usados por todos os repos da org que não têm templates próprios.

Ele é **público** porque o GitHub exige isso para os templates padrão funcionarem. Por isso, aqui só entra template: nada de código, configuração ou informação interna.

- `.github/ISSUE_TEMPLATE/`: 💡 Ideia, 🐞 Bug, ✨ Feature, 📣 Tarefa e 📝 Ata da semana. Cada um já põe a issue no quadro do time.
- `.github/pull_request_template.md`: o checklist de todo PR
