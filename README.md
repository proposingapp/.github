# .github · templates e perfil da org

Este repositório guarda os templates de issue e de pull request usados por todos os repos da org que não têm templates próprios, e o perfil público que aparece em https://github.com/proposingapp.

Ele é **público** porque o GitHub exige isso para os templates padrão e para o perfil funcionarem. Por isso, aqui só entra o que qualquer pessoa pode ver: nada de código, configuração ou informação interna.

- `.github/ISSUE_TEMPLATE/`: 💡 Ideia, 🐞 Bug, ✨ Feature, 📣 Tarefa e 📝 Ata da semana. Cada um já põe a issue no quadro do time.
- `.github/pull_request_template.md`: o checklist de todo PR
- `profile/README.md`: o perfil público da org, com o banner em `profile/assets/`. O perfil interno, só para membros, fica no repo privado `.github-private`
